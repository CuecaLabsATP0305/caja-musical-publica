# 🌍 Caja Musical Pública - Calibrador Homeostático Universal

Este repositorio aloja la arquitectura unificada y de acceso universal de la **Caja Musical**, un nodo de procesamiento en el borde diseñado bajo principios de ciencia abierta, ética médica y las leyes de la termodinámica clásica. El sistema actúa como una interfaz mimético-adaptativa que unifica los flujos de la materia viva (movimiento, habla, miradas y expresiones) en un lazo cerrado armónico y libre de fricciones distributivas.

---

## 🚀 Comando de Despliegue Unificado (Un Solo Paso)

Para inicializar el entorno, validar los sensores nativos del hardware e iniciar la inferencia neuronal local en Termux o cualquier consola Linux/ARM, ejecute la siguiente instrucción:

```bash
cd ~ && pkg update -y && pkg install -y git && git clone https://github.com && cd caja-musical-publica && chmod +x setup.sh && ./setup.sh && python monolithic_edge_core.py
```
